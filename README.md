# ngx-datetime-picker workspace

An Angular 22 workspace containing the **ngx-datetime-picker** library and an interactive demo application.

The library provides a configurable date/time picker built on `@angular/cdk` and `@angular/material`, with a TC39 Temporal adapter as the flagship default. It ships five variants: date, date-range, time, datetime, and datetime-range.

See [`projects/ngx-datetime-picker/README.md`](projects/ngx-datetime-picker/README.md) for full library documentation including entry points, providers, per-variant usage snippets, picker inputs, forms integration, theming, accessibility, and RTL support.

## Running the demo

```bash
npm start
```

Then open `http://localhost:4200` in your browser.
