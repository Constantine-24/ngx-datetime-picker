# ngx-datetime-picker v1.0.1

A maintenance release: the package is now built with the **Angular 22.2** toolchain. Nothing in the public API or runtime behaviour changes, and the supported Angular range stays **`^22.0.0`**. This is also the first release published through npm trusted publishing (OIDC) from GitHub Actions, with no long-lived npm token involved.

## Highlights

- **Built with Angular 22.2.3** (`@angular/compiler-cli`, `@angular/build`) and **ng-packagr 22.2.4**, up from 22.0.x.
- **Still works on Angular 22.0.** An Angular 22.0.2 application with Material 22.0.2 was verified to build and run against this package (inline range selection, dual-calendar datetime range overlay).
- **Material internals re-verified.** The picker relies on two pinned `MatCalendar` internals, the `_userSelection` output and the `headerComponent` input. Both are unchanged in Material 22.2.3 and covered by the integration specs.
- **Signed provenance.** Published by the `release.yml` workflow with an npm provenance attestation.

## Upgrade notes

No code changes are needed. Update with:

```bash
npm install @constantine-24/ngx-datetime-picker@1.0.1
```

None.
